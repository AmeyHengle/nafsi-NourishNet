NourishNet Data Schema

Required fields must be present for an entity to be stored. Recommended fields are prompted for if missing. Optional fields are accepted if available.

required Must have — entity rejected without it
recommended Bot asks if missing from submission
optional Accepted if present, never blocked on
🏠 Food Event entity_type: "event" — shown to families
FieldTypeTierWhy it matters
namestringrequiredCard title and map popup label
addressstringrequiredGeocoded to lat/lng — no address = no map pin
lat / lngnumberrequiredDerived from address — geocoding must succeed
date_or_schedulestringrequiredUser needs to know when — without this the listing is useless
hoursstringrecommendedOpen/close times — needed for "open now" filter
eligibilitystringrecommendedDo I qualify? Need ID? Shown prominently on card
food_typesstring[]recommendedChip display + food type filter in UI
languages_servedstring[]recommendedEN/ES badge and language filter
contactstringrecommendedUser may need to confirm or ask questions
transit_infostringoptionalBus/metro access — critical for car-free families
organizerstringoptionalName of person or org running the event
source_urlstringoptional"View details" button on card
